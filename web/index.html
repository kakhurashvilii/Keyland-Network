დამატებითი პარამეტრები და დიაგნოსტიკა
ჩართვისას Hotspot მოწყობილობები Keyland DNS-ს გამოიყენებენ. მხოლოდ დომენის მოთხოვნები ჩაიწერება; HTTPS შიგთავსი არ იკითხება.
შესაძლებლობების დეტალური ანგარიში 
მოწყობილობის შესაძლებლობები ჯერ არ შემოწმებულა.

Hotspot-ის დაკავშირებული მოწყობილობები

0 მოწყობილობა

RX — მოწყობილობის ატვირთვა; TX — ჩამოტვირთვა. სიჩქარე ითვლება ბოლო ორ გაზომვას შორის.

Hotspot ჯერ არ არის ჩართული ან მოწყობილობები არ არის დაკავშირებული.

ნაჩვენებია hostapd/iw-ის რეალური მრიცხველები. თითოეული მოწყობილობის დაბლოკვა და სიჩქარის ლიმიტი დაცული მართვის API-ით იმართება.

კონფიდენციალურობა: HTTPS კავშირების შიგთავსს, პირად მიმოწერას, პაროლებს ან ვებგვერდების შიდა შიგთავსს Keyland არ კითხულობს და არ იწერს. DNS მონიტორინგი, ჩართვის შემთხვევაში, აჩვენებს მხოლოდ DNS მოთხოვნების მეტამონაცემებს (დომენს, დროსა და მოთხოვნის ტიპს) და მხოლოდ მაშინ, როცა მოწყობილობის DNS მოთხოვნები Keyland-ის DNS სერვერზე გადის. VPN-მა, დაშიფრულმა DNS-მა ან სხვა გარე resolver-მა შეიძლება ეს ხილვადობა შეზღუდოს.

A1 / DEVICE ACTIVITY

Device Internet Activity

ნახე, რომელ დომენებს უკავშირდებიან Hotspot-ის მოწყობილობები

საიტების ისტორია მოწყობილობების მიხედვით

0 მოთხოვნა

ჩანს მხოლოდ Keyland DNS-ზე დაფიქსირებული დომენური მოთხოვნები. ეს არ ადასტურებს, რომ საიტი სრულად ჩაიტვირთა; სრული URL, HTTPS შიგთავსი და პაროლები არ იკითხება.

DNS მონიტორინგი გამორთულია ან მოთხოვნები ჯერ არ არის.

მოწყობილობის ამოცნობა ხდება DHCP lease-ის IP/MAC/hostname მონაცემებით. VPN-მა ან დაშიფრულმა DNS-მა შეიძლება ისტორია არასრული გახადოს.

Linux Shell · სრული ადმინისტრატორის ტერმინალი

სრული shell მუშაობს Keyland სერვისის უფლებებით (ამ მოწყობილობაზე — root). აქ შესრულებულმა ბრძანებამ შეიძლება შეცვალოს ან წაშალოს სისტემის ფაილები, ქსელის კონფიგურაცია ან შეწყვიტოს Hotspot/LTE. გაუშვი მხოლოდ კარგად გააზრებული ბრძანებები.

გამორთულია 
Keyland Linux Shell v1.0.0
დააჭირე „ტერმინალთან დაკავშირებას“.

უსაფრთხოება: საჭიროა მოქმედი ადმინისტრატორის სესია; WebSocket იღებს მხოლოდ იმავე საიტის Origin-ს. სესია წყდება 15 წუთი უმოქმედობის ან მაქსიმალური დროის შემდეგ. ჟურნალში ინახება მხოლოდ კავშირის მეტამონაცემები — ბრძანებები და მათი შედეგები არა.

05 / SYSTEM

სისტემის მართვა · v1.0.0

გადატვირთვა და უსაფრთხო აღდგენა. ყველა მოქმედება საჭიროებს ადმინისტრატორის დადასტურებას.

ქარხნულ პარამეტრებზე დაბრუნება

ამჟამინდელი აღდგენა შლის მხოლოდ Keyland-ის შენახულ Hotspot-ის პარამეტრებს. ადმინისტრატორის ანგარიში, კოდი და Kali Linux უცვლელი რჩება. წაშლამდე იქმნება სარეზერვო ასლი.
