Linux Shell · სრული ადმინისტრატორის ტერმინალი

სრული shell მუშაობს Keyland სერვისის უფლებებით (ამ მოწყობილობაზე — root). აქ შესრულებულმა ბრძანებამ შეიძლება შეცვალოს ან წაშალოს სისტემის ფაილები, ქსელის კონფიგურაცია ან შეწყვიტოს Hotspot/LTE. გაუშვი მხოლოდ კარგად გააზრებული ბრძანებები.

გამორთულია 
Keyland Linux Shell v0.7.0
დააჭირე „ტერმინალთან დაკავშირებას“.

უსაფრთხოება: საჭიროა მოქმედი ადმინისტრატორის სესია; WebSocket იღებს მხოლოდ იმავე საიტის Origin-ს. სესია წყდება 15 წუთი უმოქმედობის ან მაქსიმალური დროის შემდეგ. ჟურნალში ინახება მხოლოდ კავშირის მეტამონაცემები — ბრძანებები და მათი შედეგები არა.

05 / SYSTEM

სისტემა

მოწყობილობის მდგომარეობა და საჭიროების შემთხვევაში ტექნიკური ინფორმაცია

სისტემის მართვა · v0.7.0

გადატვირთვა და უსაფრთხო აღდგენა. ყველა მოქმედება საჭიროებს ადმინისტრატორის დადასტურებას.

ქარხნულ პარამეტრებზე დაბრუნება

ამჟამინდელი აღდგენა შლის მხოლოდ Keyland-ის შენახულ Hotspot-ის პარამეტრებს. ადმინისტრატორის ანგარიში, კოდი და Kali Linux უცვლელი რჩება. წაშლამდე იქმნება სარეზერვო ასლი.

სისტემის დიაგნოსტიკა

ჩვეულებრივ მართვას ეს მონაცემები არ სჭირდება. გახსენი მხოლოდ პრობლემის შემოწმებისას.
