Wi-Fi ადაპტერები და ჩიპსეტები

ადაპტერებისა და რეჟიმების აღმოჩენა აქტიურია. AP/Client/Repeater კონფიგურაცია დაემატება მხოლოდ მოწყობილობის შესაძლებლობების დადასტურების შემდეგ.

მოქმედი Wi-Fi კავშირი დაცულია; დრაივერის გადატვირთვა ავტომატურად არ შესრულდება.

Wi-Fi Hotspot

OpenWrt-ის მსგავსი AP მართვა: ცალკე AP ინტერფეისი, არჩეული WAN, DHCP, DNS და NAT. upstream ინტერფეისი არ გადაირთვება.

მაგალითი: 192.168.88.1/24. ეს იქნება Gateway; DHCP-ს dnsmasq, NAT-ს კი nftables მართავს.

DNS კლიენტებს DHCP-ით მიეწოდება; DNS მოთხოვნები არჩეულ სერვერებზე გადაიგზავნება.

მოწყობილობის შესაძლებლობები ჯერ არ შემოწმებულა.

03 / REPEATER

Wi-Fi Repeater

არსებული Wi-Fi კავშირის გამეორება ცალკე AP ქსელით

Repeater-ის მზადყოფნა

აქ გამოჩნდება AP + Client რეჟიმის, არხის თავსებადობისა და ინტერნეტის გაზიარების შემოწმება. ძირითადი Wi-Fi კავშირი არ შეიცვლება.

მზადყოფნის შემოწმება იტვირთება...
ახლომდებარე ქსელები

დაასკანერე ხელმისაწვდომი Wi-Fi ქსელები და შეამოწმე სიგნალი. ეს არ ცვლის მიმდინარე კავშირს.

ჯერ არ შესრულებულა სკანირება.

Repeater რეჟიმში WAN-ად აირჩიე დაკავშირებული Wi-Fi client ინტერფეისი. AP და client ერთ PHY-ზე ერთ არხზე იმუშავებენ; თუ დრაივერი ერთდროულ მუშაობას ვერ უზრუნველყოფს, გაშვება უარყოფილი იქნება.

04 / NETWORK

ქსელის მართვა

DNS, WAN/LAN, Firewall და დაკავშირებული მოწყობილობები

DNS-ის მართვა

ამჟამად ხელმისაწვდომია systemd-resolved-ის დროებითი DNS მართვა. მუდმივი პარამეტრები ქსელის მენეჯერის მიხედვით დაემატება.

DNS-ის მდგომარეობა იტვირთება...

WAN / LAN და DHCP

ინტერფეისების, მისამართებისა და მარშრუტების მონიტორინგი ხელმისაწვდომია. მისამართის, Gateway-ის, DHCP-ისა და MTU-ის შეცვლამდე დაემატება წინასწარი შემოწმება და უკან დაბრუნება.

Firewall და NAT

მართვა ჩაირთვება მხოლოდ აქტიური firewall backend-ის (nftables ან iptables) აღმოჩენისა და წესების სარეზერვო ასლის შექმნის შემდეგ.

05 / CELLULAR

მობილური ქსელი

SIM ბარათისა და მობილური მოდემის პარამეტრები

SIM / LTE / 5G პარამეტრები

მოდემის სტატუსი და სიგნალი უკვე იკითხება. APN-ისა და ქსელის რეჟიმის შეცვლა დაემატება ModemManager-ის მხარდაჭერის შემოწმებით და ცალკე დადასტურებით.

ქსელთან დაკავშირებული მოწყობილობები

კლიენტების აღმოჩენა და IP/MAC-ის ჩვენება დაემატება. დაბლოკვა განხორციელდება მხოლოდ ადმინისტრატორის დადასტურებით.
